# 🛡️ «Фейковый друг» — бот-тренажёр против интернет-мошенников для MAX

Кейс 2 регионального ИТ-форума «Искусственный интеллект и цифровая безопасность».

Бот имитирует переписку с мошенником. Пользователь отвечает кнопками или своими словами. Если он «клюнул», бот объясняет, на какой крючок социальной инженерии его поймали и как от него защищаться.

## Модули бота

| Модуль | Что делает |
|---|---|
| 🎮 **Тренировка** | 6 ветвящихся ситуаций: «Друг в беде», «Служба безопасности банка», «Проголосуй за меня», «Бесплатный донат», «Классный руководитель», «Лёгкий заработок» (дропперство). 45 разных концовок. |
| 🤖 **Бой с ИИ-мошенником** | Нейросеть (GigaChat или YandexGPT, работают без VPN) играет мошенника по случайному сюжету. Пользователь переписывается своими словами, а ИИ решает, раскусили его или нет. |
| 🔍 **Проверить сообщение** | Можно переслать боту подозрительное сообщение. Бот найдёт в нём приёмы манипуляции, оценит риск 🟢🟡🟠🔴 и подскажет, что делать. Работает и без нейросети, а с ней добавляет «мнение ИИ». |
| 🪝 **Крючки мошенников** | Справочник из 12 приёмов: давление временем, авторитет, запугивание, жалость, халява, фейковый друг, секретность, охота за кодами, ссылки, «маленький шаг» и другие. |
| 🏆 **Профиль и рейтинг** | Очки бдительности, звания (🐣 Новичок → 🛡️ Киберстраж), «слабое место» (на какой крючок попадаешься чаще всего), рейтинг игроков. |

**Чем бот цепляет пользователя (для презентации):** игровой формат, очки и звания, рейтинг среди друзей, ИИ-противник с новым сюжетом в каждом бою, разбор ошибок без морализаторства, ситуации из жизни подростков (донат, голосование, «подработка»).

## ⚠️ Важно про MAX: кто может создать бота

Сейчас бота в MAX может создать только **верифицированная организация, ИП или самозанятый** на платформе MAX для партнёров. Физлица, в том числе школьники, сами токен не получат. Кроме того, бот проходит модерацию.

**Что делать:** попросите вашу организацию (школу, IT-куб или Кванториум) создать бота на платформе MAX для партнёров и выдать вам токен. Сделайте это заранее, ведь модерация занимает время.

Пока токена нет, всё можно проверять **в консоли** (`python main.py --console`). Логика там та же самая.

## Запуск

### 1. Python
Нужен Python 3.9 или новее ([python.org](https://www.python.org/downloads/)). При установке на Windows поставьте галочку **Add Python to PATH**.
**Ничего доустанавливать не нужно**: бот использует только стандартную библиотеку.

### 2. Сертификат Минцифры
Сервер MAX API (`platform-api2.max.ru`) использует сертификат Минцифры. Скачайте **корневой сертификат** («Russian Trusted Root CA») на странице [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt) и положите файл (`.cer` или `.crt`) в папку `certs/`.
Тот же сертификат нужен и для GigaChat.

### 3. Настройки
Скопируйте `config.example.json` в `config.json` и впишите токен бота:
```json
{ "max_token": "токен из настроек бота на платформе MAX" }
```

### 4. Старт
- Windows: дважды щёлкните `start.bat`
- или в терминале: `python main.py`

Проверка без MAX: `start_console.bat` или `python main.py --console`. Цифра нажимает кнопку, текст отправляется как сообщение.

## Подключение нейросети (по желанию)

Без нейросети работают все модули, кроме «Боя с ИИ».

**GigaChat (бесплатно для физлиц):**
1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru/studio) и создайте проект GigaChat API.
2. Скопируйте **ключ авторизации** (Authorization key).
3. В `config.json`:
```json
"ai_provider": "gigachat",
"gigachat_auth_key": "ваш ключ авторизации"
```

**YandexGPT:** создайте в Yandex Cloud сервисный аккаунт с ролью `ai.languageModels.user` и API-ключ, затем:
```json
"ai_provider": "yandex",
"yandex_api_key": "...",
"yandex_folder_id": "..."
```

## Как добавить свою ситуацию

Все тексты лежат в `scenarios.json`, код трогать не нужно. Сюда удобно переносить логи переписок, которые дадут организаторы.

```json
"my_case": {
  "title": "Название", "emoji": "📦", "difficulty": 2,
  "who": "Кто пишет",
  "intro": "Описание ситуации",
  "start": "s1",
  "steps": {
    "s1": {
      "messages": ["Реплика мошенника 1", "Реплика 2"],
      "hooks": ["urgency", "code"],
      "options": [
        {"text": "Ответ, который ведёт дальше", "result": "next", "goto": "s2", "comment": "Подсказка"},
        {"text": "Опасный ответ", "result": "hooked", "hook": "code", "explain": "Почему это ошибка"},
        {"text": "Правильный ответ", "result": "safe", "explain": "Почему это правильно"}
      ]
    }
  },
  "red_flags": ["Красный флаг 1", "Красный флаг 2"]
}
```
- `narration` — необязательный текст «от автора» в шаге (например, «📱 Приходит СМС…»).
- Текст кнопки — до ~40 символов, чтобы помещался на экране телефона.
- Список крючков (`hooks`) и слова, по которым их ищет проверка сообщений, хранятся в `hooks.json`.

## Файлы

```
main.py           запуск: MAX или консоль
engine.py         логика тренажёра (меню, сценарии, очки, рейтинг)
max_api.py        клиент MAX Bot API
analyzer.py       проверка сообщения на крючки
ai.py             GigaChat / YandexGPT, режим «Бой с ИИ»
scenarios.json    ситуации
hooks.json        справочник приёмов манипуляции
config.json       ваши ключи (не публикуйте его!)
certs/            сертификат Минцифры
data/users.json   прогресс игроков (создаётся сам)
```

Бот работает через long polling: ему не нужен белый IP и домен. Достаточно держать запущенным компьютер с интернетом.
